На момент написания readme я сделал:
1) Подключился в БД. Она поднимается в докер-контейнере. 
Команда для запуска: docker compose up --build

2) В проекте есть две миграции. Первая миграция это создание сущности для пользователя, втоорая миграция это добавление сущности для работы с Токенами
Запустить миграции можно с помощью команды "npm run migrate"

3) Написаны несколько ручек для взаимодействия с програмомой. 
Первая: Регистрация пользователя. (POST auth/sign-up)
Вторая: Вход пользователя. (POST auth/sign-up) 
Третья: Посмотреть информацию о себе (POST user/)
Плюс несколько дополнительных ручек для работы с jwt-токеном

4) Для работы с Базой данных использовалась TypeORM.
